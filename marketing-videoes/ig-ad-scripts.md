# EduBuddy: 4 Instagram ad scripts (30s, English, demand test)

Audience: coaching institute owners. Priority order: fees collection, then attendance, then enquiries, all framed as institute growth.
Features covered: automatic fee-reminder calls to parents, one-click receipt save, update records from a photo, reports, attendance reports, PYQ PDFs.
Some of these are not built yet. These scripts are for testing demand before the app has them.

Format for every script: 9:16, burned-in captions (most people watch muted), hook inside the first 2 seconds, CTA "Book a free demo".

---

## Notes for testing
- Run all 4 as separate ads in one ad set (same audience, same budget). Use each script's hook A first, then test B and C on the winner.
- Judge hooks by 3-second view rate (thumb-stop), the body by hold rate / ThruPlays, and demand by cost per demo booked.
- Script 3 opens with audio, so it depends on sound being on. Burn the call transcript in as captions so it still works muted.
- Since these features are not built yet, a "Book a free demo" or "Get early access" CTA is the safer choice. Make sure the demo or landing page tells people honestly what is live today and what is coming, so the leads stay useful and nobody feels misled.
